Workshop: HTML Heading

ฝึกใช้แท็ก <h1> – <h6> และการปรับขนาดหัวข้อด้วย CSS

1. ความหมายของ Headings (H1–H6)

Headings มีทั้งหมด 6 ระดับ ตั้งแต่ H1 ถึง H6 ซึ่ง H1 เป็นหัวข้อใหญ่สุด และ H6 เป็นหัวข้อเล็กสุด

H1 – หัวข้อใหญ่สุด ใช้สำหรับชื่อหน้าเว็บหรือหัวข้อหลัก

H2 – หัวข้อรอง แบ่ง Section ของเนื้อหา

H3 – หัวข้อย่อยภายใน H2

H4 – ย่อยลงไปอีกระดับ

H5 – ใช้น้อย แต่เน้นลำดับข้อมูล

H6 – เล็กสุด ใช้กับหัวข้อระดับลึก

2. ตัวอยางการใช้ H1–H6

                            
        <h1>Welcome to My Website</h1>
        <h2>HTML Basics</h2>
        <h3>What is HTML?</h3>
        <h4>HTML Syntax</h4>
        <h5>Example Code</h5>
        <h6>Note: Case Sensitive</h6>

ผลลัพธ์ที่ได้จากโค้ดด้านบน

H1: Welcome to My Website

H2: HTML Basics

H3: What is HTML?

H4: HTML Syntax

H5: Example Code
H6: Note about heading size

คำแนะนำ: ใช้เพียงหนึ่ง <h1> ต่อหน้า – เพื่อแสดงถึงหัวข้อหลักหรือหัวเรื่อง

หมายเหตุ: ใช้หัวข้อ HTML สำหรับหัวข้อเท่านั้น ห้ามใช้หัวข้อเพื่อทำให้ข้อความ ตัวใหญ่หรือตัวหนา
